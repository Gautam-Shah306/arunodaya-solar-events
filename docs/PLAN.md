# Arunodaya Implementation Plan

The project executes across a sequenced delivery plan of 13 prompts.

| Prompt | Name                                                                 | Status   | Scope Description                                                                                                                                                                                                                                                                             |
| ------ | -------------------------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | Foundation                                                           | COMPLETE | Rules, docs, npm-workspaces monorepo, quality gates, invariants checker, app shell, CI and GitHub Pages deploy.                                                                                                                                                                               |
| 1b     | Repair after Prompt 1                                                | COMPLETE | Invariants scanner real repo coverage, spec alignment to v2 contract, workflow lint, CodeQL and Dependabot hardening.                                                                                                                                                                         |
| 1c     | CI repair                                                            | COMPLETE | Linux CI reproduction and fix, verify:linux Docker script, CodeQL default mode alignment, readable verify CI logs.                                                                                                                                                                            |
| 2      | Contracts and time core                                              | COMPLETE | Snapshot data contracts and validators, epoch-millisecond instant model (`Ev`), civil date core, strict IST time utilities, display rounding, countdown logic, greeting selection, day/night derivation, snapshot status, BOM invariant, `verify:linux -- --index`, and timezone test matrix. |
| 3      | Reference data and engine selection                                  | COMPLETE | Reference data (Skyfield with NASA/JPL DE440s, PyEphem cross-check), candidate benchmark against ±1m/±2m tolerances, decision (astronomy-engine), and docs.                                                                                                                                   |
| 4      | Astronomy provider and snapshot builder                              | COMPLETE | Path-scoped dependency allowance for astronomy-engine, day record derivation, snapshot builder, golden tests (quick and full), and nightly workflow.                                                                                                                                          |
| 5      | Theme system (10 themes)                                             | COMPLETE | Ten themes as typed data, colour maths, 45-point contrast gate, runtime application helper, theme gallery page for visual review, and preview server.                                                                                                                                         |
| 6      | App shell and Home                                                   | PENDING  | React application setup, early-paint script to prevent theme flash, prominent numerical typography, home screen layout, rolling digit odometer; wraps snapshot builder in a Web Worker to offload calculations.                                                                               |
| 7      | Location                                                             | PENDING  | Geolocation adapter, offline India city database, coordinate search, and manual selection fallback.                                                                                                                                                                                           |
| 8      | Forecast/Astronomy/date picker/next moonrise/Settings/theme selector | PENDING  | Seven-day forecast, Astronomy view, date navigation, next moonrise, Settings view, and theme selector UI.                                                                                                                                                                                     |
| 9      | Monthly PDF and share card                                           | PENDING  | Canvas/SVG share card export and monthly printable solar calendar PDF generation.                                                                                                                                                                                                             |
| 10     | PWA and Pages hardening                                              | PENDING  | Service worker, Web App Manifest, offline caching, install prompts, and Lighthouse optimization.                                                                                                                                                                                              |
| 11     | Android shell and bridge                                             | PENDING  | Capacitor integration, Android wrapper, native bridge communication, and web asset bundling.                                                                                                                                                                                                  |
| 12     | Widgets                                                              | PENDING  | Android AppWidget provider, Jetpack Glance layout implementations, and periodic alarm/update scheduling.                                                                                                                                                                                      |
| 13     | Hardening and release                                                | PENDING  | Security review, performance profiling, final NOTICE and licence audit, and store release packaging.                                                                                                                                                                                          |
